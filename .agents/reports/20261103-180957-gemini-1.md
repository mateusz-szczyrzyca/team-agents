## Deliverables in Round 3

1. **Subprocess execution boundaries (`agent/process.go`):**
   - Interfaces `Executor` and default `OSExecutor` with context cancellation, process error mapping, environment clearing/setting, cwd handling, and stdin/stdout/stderr streaming.
   - Fail-closed execution: `deniedExecutor` fails with `ExecuteDenied` by default.
   - Stream error retention: stdin and stdout/stderr stream copy failures are preserved and returned as `ExecuteWait` before ordinary exit codes.
   - Writer value comparability check: safe handling of interface-valued fields containing slices to avoid runtime panics during writer equality checks.
2. **Clock and random boundaries (`agent/time_random.go`):**
   - `Clock` interface with `realClock` adapter.
   - `Random` interface with mutex-guarded seeded `mutexRandom`.
3. **Application wiring (`agent/app.go`):**
   - `App` struct holding `Executor`, `Clock`, and `Random` dependencies.
   - Zero-value `App` and `newApp(nil, ...)` fail closed with `ExecuteDenied`.
   - `main.go` wires `OSExecutor{}`, `realClock{}`, and seeded `mutexRandom`.
4. **Typed error mapping (`agent/errors.json`, `agent/errors.go`):**
   - `Execute` operation with causes `InvalidCommand`, `Denied`, `Start`, and `Wait`.
   - `fromProcess` helper mapping low-level execution errors to typed `ExecuteError`.
