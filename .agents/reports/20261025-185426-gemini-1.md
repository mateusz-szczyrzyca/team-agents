## Review Pass 2 Findings and Resolution

Investigation #36 (`inv-astra`) identified 4 major findings and 1 minor finding on `5b1ec0d`:
1. **Major M1 (`meta_set` failure propagation)**:
   - Calling `meta_set` inside `if !` in `create_task` disables errexit. A failure during metadata write was masked by the subsequent `mv`, allowing `create_task` to return 0 with incomplete metadata.
   - **Resolution**: `meta_set` now checks the write and rename separately inside its subshell, exits non-zero before `mv` if write fails, and removes temporary files. Covered by Bats fault-injection tests (`RED 1a3c826` / `GREEN aa13a01`).
2. **Major M2 (Isolated private fetch ref)**:
   - `nodeCheckout` fetched into the clone's shared `FETCH_HEAD` outside the task lock; concurrent checkouts or external fetches could overwrite `FETCH_HEAD` before resolution, resolving the wrong commit.
   - **Resolution**: `nodeCheckout` now allocates a crypto-random unique ref under `refs/team-agents/node-checkout/<nonce>`, fetches directly into that private destination (`target:refs/...`), resolves the immutable commit from the private ref, and deletes the ref in a deferred cleanup logging any failure via `warnSideEffect`. Verified by real-Git deterministic interleaving tests covering both external human fetch and nested preparation (`RED 98f7109` / `GREEN ba80c98`).
3. **Major M3 (Focused failure-path coverage and test-first compliance)**:
   - Added focused failure-path tests in `tests/unit/node_checkout.bats` for `task.md` write failure, `meta.env` initialization failure, and metadata write failure propagation (`RED 1a3c826` / `GREEN aa13a01`). Also covered post-checkout agent admission recheck under task lock (`RED 3dd3017` / `GREEN 5b3dc62`).
4. **Major M4 (ShellCheck and ineffective assertions in `node_checkout.bats`)**:
   - `! git show-ref ...` in Bats did not fail the test when the branch survived (`SC2314`).
   - `NODE_REPOS` triggered `SC2034` in `node_job_setup`.
   - `Makefile:SHELL_SCRIPTS` omitted `tests/unit/node_checkout.bats`.
   - **Resolution**: Included `tests/unit/node_checkout.bats` in `Makefile:SHELL_SCRIPTS`, changed branch assertion to explicit status check (`run git ...; [ "$status" -eq 1 ]`), and added inline ShellCheck disable explanation (`# shellcheck disable=SC2034 # NODE_REPOS is read by prepare_job_task, which is defined in the sourced bin/agent`). Zero lint findings across all modules.
5. **Minor m1 (PR description update)**:
   - Removed obsolete `WorktreeFailed`, updated PR commit history with actual commit subjects, updated verified test counts, and listed all lint suppressions.
