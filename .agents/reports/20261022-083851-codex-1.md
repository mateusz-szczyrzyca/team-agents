## Unix socket transport follow-up

Added an independently tested local HTTP-over-Unix-socket transport. It sends no bearer token and verifies
socket ownership, owner-only access, absence of a socket symlink and a parent directory that other users
cannot modify. Missing or refused sockets return typed Unavailable errors. Focused tests and the race
suite pass. The human approved the narrow interim-fallback test update in resumed round 2. Production routing now
selects the socket for HUB_LISTEN or an explicit HUB_SOCKET; missing sockets return Unavailable. Only
the authorized fallback assertion block in TestHubClientEnvironmentAndPinnedTLS was changed. New routing
tests cover default and explicit paths, --dir selection, token-free local transport and no local bus writes.

Three test-only gosec suppressions explain deliberate permission setup: chmod 0700 allows traversal of a
private test directory; chmod 0666 creates an insecure socket to test rejection; chmod 0777 creates an
insecure parent directory to test rejection. These must be listed in the final PR description.

Integration review found that the new listener's default resolver trusted caller-supplied identity.
The coordinator assigned the listener owner a fail-closed correction. The coordinator integrated the fail-closed correction in 0bc1ba6. M1 remains incomplete until the other
documented integration gaps are resolved. A further listener review identified separate executor state
for TCP and Unix, ignored cleanup errors and incomplete network/body restrictions; the listener owner
was notified and owns those corrections.

The interim lead_local_fallback event is retired: its stable name remains declared for old logs, but
production socket routing no longer emits it. The PR description must mention removal of the fallback
and the explicit human authorization for the one interim test update.

directory, is not remote input, and is inspected for ownership and access restrictions. Include both in
