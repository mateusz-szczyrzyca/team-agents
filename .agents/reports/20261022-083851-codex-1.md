## Unix socket transport follow-up

Added an independently tested local HTTP-over-Unix-socket transport. It sends no bearer token and verifies
socket ownership, owner-only access, absence of a socket symlink and a parent directory that other users
cannot modify. Missing or refused sockets return typed Unavailable errors. Focused tests and the race
suite pass. Production routing is intentionally not activated until the human authorizes updating the
newly-added interim-fallback assertion; no existing test has been changed for this follow-up.

Three test-only gosec suppressions explain deliberate permission setup: chmod 0700 allows traversal of a
private test directory; chmod 0666 creates an insecure socket to test rejection; chmod 0777 creates an
insecure parent directory to test rejection. These must be listed in the final PR description.

Integration review found that the new listener's default resolver trusted caller-supplied identity.
The coordinator assigned the listener owner a fail-closed correction. M1 remains incomplete until that
fix, socket routing and the other documented integration gaps are resolved.
