# Go rewrite — round 3

[PR #50](https://github.com/mateusz-szczyrzyca/team-agents/pull/50) adds Go
application-owned execution, time and random boundaries. Production remains
Bash; the candidate retains its help skeleton. Review corrections and final
checks are recorded in [the resumed report](20261103-144857-codex-1.md).

## Delivered

- `Command` preserves argv, environment, working directory and caller-owned streams.
- `OSExecutor` runs direct subprocesses synchronously with typed start/wait causes.
- Unconfigured execution is denied; the binary explicitly installs `OSExecutor`.
- Injected `Clock` and per-instance mutex-protected seeded `Random` enable tests.
- Fixtures use the test executable and temporary files; cancellation coverage
  includes a readiness handshake verifying that the direct child is reaped.
- All `520` Bats parity cases remain `planned`; activation begins in R04.

## Compatibility and limitations

No persisted formats, public commands, bus tools or production Bash changed.
Go `1.22` remains the minimum; no dependency was added. The existing `#nosec G204`
suppression documents intentional direct argv execution in `agent/process.go`.
Caller streams remain caller-owned; random draws are noncryptographic.

An existing cancellation test retains a `100` ms startup deadline and uses
`os.Args[0]`; relative-path manual test-binary invocation is not verified.
The separate readiness-handshake test avoids that startup assumption.
R04 Bats activation and R20 descendant lifecycle management remain later work.
