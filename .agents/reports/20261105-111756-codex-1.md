## Changes and compatibility

The candidate now parses literal legacy metadata, preserves source bytes and unknown records,
formats Bash-compatible assignments, reads task files with typed errors, and resolves task IDs
against the Bash oracle. Both C and UTF-8 encodings decode; formatting follows C.UTF-8.
Absent fields differ from empty fields. Unknown historical field values are not enum-validated.
Task lookup retains exact-directory precedence, literal fragments, hidden exact references,
directory symlinks, path-like references and the empty-directory glob quirk.

Unsupported shell records remain opaque and are never executed by the native parser.
The new APIs are internal and unwired: existing command sourcing and caller behavior remain
Bash-owned. This is no claim of executable-metadata parity or completed consumer migration.
Unicode quoting follows Go's tables; another libc version can quote newly assigned runes
differently while preserving decoded bytes.

The live panel now decodes the four ANSI control escapes Bash already writes.
No existing test, helper, stub, ledger activation or installation was changed.
