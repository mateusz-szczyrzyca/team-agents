## Fix pass 1: Review findings resolution

The round underwent review by investigators `inv-astra` (codex, request #181) and `inv-kimi` (opencode, request #182). All findings were resolved with strict test-first commits:

1. **Missing bus execution and notice delivery (inv-astra #1):**
   - Added `busCmd(ctx, app, busBin, args...) (string, *BusError)` invoking `agentbus` subcommands through `App.execute`, mapping non-zero exit codes with `mapBusExitCode` and process execution failures to `BusProcess`.
   - Added `sendNotice(ctx, app, logger, busBin, busDir, kind, from, to, text, fields...) *LogWriteError` constructing `send --dir ... --from ... --to ... --notice ... --field ... text`, executing via `Try` with `LogNoticeFailed` (warning-only side effect), and logging delivery via `LogNoticeSent`.
   - Tested through injected `busTestExecutor` in `TestBusCmd` and `TestSendNotice`.

2. **Zero bus limits change meaning (inv-astra #2, inv-kimi #1):**
   - Updated `busArgsJSON` to unconditionally pass `--queue-max` and `--inv-slots` in Bash argument order, preserving zero limits without falling back to `agentbus` defaults.
   - Added regression test `TestBusArgsJSONZeroLimits`.

3. **Large bus messages breaking scanner (inv-astra #3, inv-kimi #2):**
   - Replaced default 64 KiB `bufio.Scanner` with `bufio.Reader.ReadBytes('\n')` in `busMessagesFrom`, supporting arbitrarily large valid JSON lines without token limits.
   - Added regression test `TestBusMessagesFromLargeRecord` with 75 KiB message body followed by subsequent records.

4. **Concrete storage errors and joined close failures (inv-astra #4, inv-kimi #3):**
   - Updated `busMessagesFrom` return signature from `(int, error)` to concrete `(int, *StorageError)`, wrapping open/read/close errors with `storageErr` and joining close failures via `errors.Join`.
   - Added test `TestBusMessagesFromStorageError` asserting `*StorageError` and `ErrStorage`.

5. **ScriptNotice JSON decoding validation (inv-astra #5, inv-kimi #4):**
   - Implemented `ScriptNotice.UnmarshalJSON` rejecting unknown notices and non-string JSON values with `*ValueError`.
   - Added test `TestScriptNoticeJSON` testing valid, unknown, and non-string JSON decoding.

6. **ScriptNotice.Valid test-first history (inv-astra #6, inv-kimi #5):**
   - Corrected branch history so `ScriptNotice.Valid` was a failing stub returning `false` at RED commit `c22b21a` (with failing test run recorded in commit message) and implemented at GREEN commit `eeb8478`.
