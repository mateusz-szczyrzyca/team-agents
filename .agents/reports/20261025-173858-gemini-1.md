## Round 5 Scope & Implementation

Following the human-approved nine-round plan in `docs/multi-instance.md`, Round 5 implements:
1. **Typed Error Causes (`agentbus/errors.json`)**:
   - Declared operation `node/checkout` with causes: `BadFlags`, `MissingArgument`, `RepositoryNotAllowed`, `InvalidRepository`, `InvalidBaseRef`, `InvalidCommit`, `FetchFailed`, `CheckoutFailed`, `WorktreeFailed`, and generated `Storage` for output serialization.
2. **Node Checkout Adapter (`agentbus/node_checkout.go`)**:
   - `nodeCheckout(repos map[string]string, req NodeCheckoutRequest) (NodeCheckoutResult, *NodeCheckoutError)`
   - Validates that the requested repository is configured in the local `NODE_REPOS` map (`NodeCheckoutRepositoryNotAllowed`).
   - Validates ref name and commit SHA using `validJobBase`.
   - Fetches from `origin` using package-variable `callNodeGit` without switching or checking out the local clone, and resolves the immutable commit SHA.
   - CLI subcommand `agentbus node-checkout --repo <name> --base <ref> [--sha <sha>] --repo-path <name>=<path>...` emitting `{root, commit}` JSON.
   - Replaced both round-5 pending skips (`TestNodeRefusesRepositoryOutsideAllowList`, `TestNodeCheckoutFailureFailsJobWithReason`) with executable unit tests.
3. **Shared Task Preparation (`bin/agent`)**:
   - Enhanced `create_task` to accept an optional start commit (defaulting to `HEAD`), preserving `cmd_run` and existing test behavior while enabling node jobs to start worktrees at resolved immutable commits.
   - Implemented `prepare_job_task`: resolves repositories from `NODE_REPOS` via `agentbus node-checkout`, creates worktrees and metadata via `create_task`, logs `node_checkout_failed` on error, and exits without starting runners.
   - Added `declare -A NODE_REPOS=()` in `config/agents.conf` and `bin/agent`.
   - Added unit test suite `tests/unit/node_checkout.bats` verifying commit pinning, allow-list refusal, and non-existent ref failures.
4. **Documentation**:
   - Updated `README.md` ("Several instances") describing `NODE_REPOS`, `agentbus node-checkout`, and `prepare_job_task`.
   - Updated `docs/multi-instance.md` roadmap status for Round 5.
