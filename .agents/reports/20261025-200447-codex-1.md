## Implementation and review

- `agent node [--once]` validates configuration without contacting the lead, then holds a lifetime lock.
- Assignment preparation and launch reuse `prepare_job_task`, `create_task` and `start_runner`.
- Prepared jobs reserve their configured local agent while awaiting the lead's start acknowledgement.
- Exact start reports are persisted before sending and retried without changing timestamps. Local pending
  entries drive recovery even when a successful lead acknowledgement was lost.
- Started tasks keep running during a lead outage. A job-only local transition journal captures rapid waits
  and resumes; pending reports retain cumulative history until accepted.
- Rejected expired assignments are reconciled with the lead and cannot authorize a launch.
- Cancellation requires successful local stopping, preserving terminal completion when it wins the race.
- `node-request` bounds requests/replies and timeouts, disables proxies and redirects, and classifies failures
  with `NodeClient` causes. Its optional source-address flag is used by the loopback identity fixture.
- Heartbeats add bounded, ownership-scoped `Stops`, repeated until a terminal report acknowledges them.
- Checkout failure diagnostics include the existing typed cause name, so job results remain actionable.

RED/GREEN evidence includes coordinator `25827bc` / `a7ddd29`, safety RED `3267ff7`, service
RED `5731416` / GREEN `e19cfd1`, and member daemon/acceptance RED commits merged into the integration.
New test fixtures were corrected before acceptance: separate exported homes, realistic full acknowledgements,
deterministic terminal-state waits, PascalCase report fields and capture of actual report batches.
Existing baseline tests were not changed. The existing stub only gained a new action.

The last review added RED `035b6f6`: a cancelled prepared task must never launch, and a failed job identity
metadata write must fail preparation and remove its checkout. Both targeted regressions pass with the final
terminal-state guard and explicit conditional-write checks.
