# Round 8 — remote delegation

## Result

`delegate` accepts optional `requires`, captures the requester's commit and routes locally when the installation has the declared capabilities. Otherwise its node daemon verifies that the commit is reachable from the requester's branch on `origin`, freezes a job submission and retries it durably through lead outages. Terminal jobs return the ordinary helper-result notice with their state, node, branch, optional PR and result head.

The human approved origin ancestry verification and durable retry without a new timeout. Questions and notifications remain on the executing node. Agents continue using their independent local buses.
