## Implementation

- Public `agent run --investigation` starts the initial pipeline, preserving validation and independent phase-one work.
- A uniform choice selects from eligible, available investigators. A decimal seed reproduces choices in tests; unseeded selection uses OS entropy and rejection sampling.
- Merger and reviewer child records are persisted before launch. The cohort retains capacity through checks and reviews; quota pauses and other reservations keep selection queued.
- The merge prompt uses the recorded published commits, requires individual incorporation/discard explanations, preserves test-first history, and opens a PR before automated checks.
- Prechecks run in uniquely named units; interrupted checks enter the same bounded failure path. Review admission verifies that the published result still matches the checked commit.
- The review uses the existing `prompts/review.md` and requires an explicit verdict. Findings alone cannot complete it.
- Handoff records a pending marker before clearing capacity. Supervision completes interrupted comment/notification attempts; flags record completed local attempts, and a crash before persistence can repeat an external action.
