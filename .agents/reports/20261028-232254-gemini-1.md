## Implementation details (Decision 13)

1. **Mirrored task loading in snapshot:**
   - Added `live/data_mirror.go:loadMirroredTasks(s *Snapshot, busDir string, ttl time.Duration)` to scan `<busDir>/remote/<node>/<task-id>/`.
   - Reads `metadata.json` via local enumeration and joins with web job registry.
   - Enriches `Task` model with `Node`, `NodeOffline`, `Note`, and sets task ID to `<task-id>@<node>`.
   - Detects node offline state via `webNodeOffline` and node TTL.

2. **Web views for mirrored tasks:**
   - URL `/task/<task-id>@<node>` renders mirrored task with title `agent@node · <task-id>@<node>`.
   - Tab rendering:
     - `activity`: live SSE event stream connected to `/events/task/<task-id>@<node>`.
     - `prompt`: prompt runs rendered.
     - `questions`: lists question rounds inferred from `questions-<n>.md` filenames.
     - `report`: final message from `final.md`.
     - `errors`: lists error logs from `err-*.log`.
     - `meta`: reads `metadata.json` via `readMetadataJSON` (with `warnOnce` logging).
     - `investigations` and `notebook`: render clear notices that they are not mirrored to the lead.
   - Guarded `/agents` and `/agents/{id}` to link to mirrored tasks when present.

3. **Security and lifecycle guards:**
   - In `live/web_views.go:loadAnswer`: direct requests for mirrored tasks are rejected with `AnswerNotWaiting`.
   - In `live/web/templates/task.html`: the "Answer" button is hidden for mirrored waiting tasks on the lead until Round 4.
   - In `live/web_views.go:postStop`: POST to `/task/<id>@<node>/stop` returns 403 Forbidden.
   - In `live/ui.go`: terminal panel `s` (stop) and `a` (answer) keys reject operations on mirrored tasks with flash notices; false dead-process labels are suppressed for remote tasks.
   - In `live/web_views.go:viewLogs`: `nodeFilter` is validated strictly against enumerated `allNodes` to prevent path traversal.

4. **Logs and dashboard integration:**
   - `/logs`: aggregates node entries from `bus/remote/<node>/logs.jsonl` with a Node column, task links to `/task/<task>@<node>`, and supports filtering by node.
   - Dashboard: displays mirrored tasks, suppresses duplicate remote job rows, shows last known state with `(node offline)` when heartbeat expires, and hides stop buttons on the lead.
