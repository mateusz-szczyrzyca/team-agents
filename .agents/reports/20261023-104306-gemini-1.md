## 3. Work Breakdown and Deliverables

### Critical C1 & Major M1, M10, M11 (codex-1 — B14)
- **C1: Secure Remote Team DTO & Host Protection:** Separated authenticated instance operator identity from registered agent MCP callers. The Hub enforces a strict remote team creation DTO omitting `WakeCmd` and `Home` fields, preventing caller-supplied executable execution on the Hub. All member identities must be qualified (`agent@instance`) and task IDs validated.
- **M1: CLI Forwarding & Dispatcher:** Installed the CLI dispatcher on both TCP and owner-only Unix socket (`hub.sock`). Forwarded `cmd-enqueue` directly to the Hub without local fallback.
- **M10: Error Contracts & State Transitions:** Harmonized shared create/set/done logic across local and remote paths, preserving exact timestamps, creation/resume/completion events, final exclusion semantics, and pending-work wakes. Propagated typed `Storage` cause on forwarded stdout failures.
- **M11: Sanitized Operator Projections:** Filtered private state: `instances` returns public manifest data without lease credentials or session tokens; `team-get` requires member ownership on requesting node and strips private quiz/consultation state. Resumed teams duplicate private qualification and board state Hub-side without exposing it to callers.

### Major M8 & M9 (openrouter-haiku — B14/M8 & B15)
- **M8: First-Attempt Outage Accounting:** Recorded hub outage on the very first transport failure (`HubClient.Observe`), bounding hang watchdog time accurately during network drops.
- **M9: Real-Home Syscall Write Guard:** Implemented a Linux/amd64 `ptrace` supervisor with a `seccomp` filter intercepting `open`/`openat` syscalls with write flags across all goroutines and child processes. Closed files and completed writes to the host agents directory are detected and denied with `EACCES`, failing the suite if violated. Added self-check probe (`TestGuardSelfCheckDetectsClosedWrite`). Non-amd64/non-Linux platforms retain the descriptor leak audit.

### Major M2, M3, M4, M5, M6, M7, M12 (gemini-1 — Coordinator)
- **M2: Remote Provisioning & Task Preservation:** Enforced `NODE_ACCEPT_REPOS` validation in `agent node`. Verified worktree creation without silent errors. Provisioned remote task descriptions into `$dir/task.md`.

- **M4 & M7: Pre-Transact Sensitive Approvals:** Gated sensitive capabilities (`sign:*`, `publish:*`) via `node/approved-capabilities.json`, checked prior to `transact` only when `sensitiveOf(requires) > 0`, allowing ordinary items to proceed without an approvals file.

- **M6: macOS Portability & Power Management:** Replaced `mapfile` with portable loops for bash 3.2 compatibility on macOS. Corrected LaunchDaemon PATH to prioritize `/opt/homebrew/bin:/usr/local/bin`. Implemented fallback direct runner execution for Darwin/non-systemd hosts. Reconciled `BATTERY_PAUSE` configuration and power detection (`is_on_battery`).
