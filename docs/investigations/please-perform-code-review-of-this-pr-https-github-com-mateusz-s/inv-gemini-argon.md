## Blockers (from Phase 1 `inv-astra`, verified in source)

1. **[COR, TDD-2, TDD-6; item 8.5, every push]** [`crates/agent/src/daemon/owner/rounds/publish.rs`](https://github.com/mateusz-szczyrzyca/team-agents/blob/72344f3b37ecc5d63a92a9289c323c0891158948/crates/agent/src/daemon/owner/rounds/publish.rs#L179-L209) — When `open_pull_request` pushes a corrected head after `check_before_review` previously sent a draft pull request back, `github.find_open_pull_request(head_branch)` returns `Some(found)` and records neither `PullOpened` nor `PullPushed` → record `HistoryEvent::PullPushed` whenever a push updates an existing open draft pull request, and test the check-send-back republish path.
2. **[COR, TDD-2, TDD-6; item 8.5, capture losses]** [`crates/agent/src/daemon/gate.rs`](https://github.com/mateusz-szczyrzyca/team-agents/blob/72344f3b37ecc5d63a92a9289c323c0891158948/crates/agent/src/daemon/gate.rs#L317-L343) — If a gate command ran (`run_command` completed) but the post-command `inspect(&job.worktree)` fails (`GateError::GitAfter`) or `save_gate_record` fails (`GateError::Record`), `Service::execute` returns early before `self.record(job, started_at, &record)` and leaves `HistoryHealth.lost` at `0` → count post-command Git capture failures under their capture cause, and record the completed gate in history even if saving the state-side gate file fails.
3. **[COR, TDD-6; item 8.5, write/read equality]** [`crates/agent-runtime/src/history/reader/sequenced.rs`](https://github.com/mateusz-szczyrzyca/team-agents/blob/72344f3b37ecc5d63a92a9289c323c0891158948/crates/agent-runtime/src/history/reader/sequenced.rs#L24) — `EVENT_CUTS` lists `["issues", "title", "body", "report", "findings", "text"]` and omits `"detail"`, even though `HistoryEvent::texts_mut` in [`crates/agent-core/src/history/event.rs`](https://github.com/mateusz-szczyrzyca/team-agents/blob/72344f3b37ecc5d63a92a9289c323c0891158948/crates/agent-core/src/history/event.rs#L353) truncates `HistoryEvent::Lost { detail, .. }` under `"detail"`; a truncated loss note writes `cut = "detail"` and causes `round_records` / `team_records` to fail with `UnknownCutField { field: "detail" }` → add `"detail"` to `EVENT_CUTS` and test boundary/non-ASCII truncation round-trips for `HistoryEvent::Lost`.
4. **[SEC-2, TDD-6; item 8.5, no secrets]** [`crates/agent-core/src/history/event.rs`](https://github.com/mateusz-szczyrzyca/team-agents/blob/72344f3b37ecc5d63a92a9289c323c0891158948/crates/agent-core/src/history/event.rs#L376) — `HistoryEvent::identities` for `Self::Gate { task, record, .. }` checks `task.as_str()` and `record.result.head.as_str()` but omits `record.result.log.as_str()`, allowing a configured secret in the gate log path to be written into `history.db` and its WAL → include `record.result.log.as_str()` in `HistoryEvent::identities` and test SQLite/WAL bytes for a gate whose log path contains a configured secret marker.
5. **[COR, TDD-2; item 8.5, merge commit]** [`crates/agent/src/daemon/owner/rounds/merges.rs`](https://github.com/mateusz-szczyrzyca/team-agents/blob/72344f3b37ecc5d63a92a9289c323c0891158948/crates/agent/src/daemon/owner/rounds/merges.rs#L166-L168) and [`crates/agent-runtime/src/github.rs`](https://github.com/mateusz-szczyrzyca/team-agents/blob/72344f3b37ecc5d63a92a9289c323c0891158948/crates/agent-runtime/src/github.rs#L1717-L1747) — `try_merge` maps `PullState::Merged` to `Merge::Merged(None)` because `RawPull` does not decode `merge_commit_sha`, losing the merge commit for human merges (`--no-merge`) and polled/recovered merges without counting a loss → decode `merge_commit_sha` into `RemotePullRequest`, pass it into `HistoryEvent::PullMerged`, and test external/polled merges.
6. **[PERF-3]** [`crates/agent-runtime/src/history/reader/sequenced.rs`](https://github.com/mateusz-szczyrzyca/team-agents/blob/72344f3b37ecc5d63a92a9289c323c0891158948/crates/agent-runtime/src/history/reader/sequenced.rs#L261-L270) — `record_of` for `RecordKind::Step` linearly scans the cached `Vec<Stored<Step>>` of the run on every step row (`find(|step| step.value.number.get() == number)`), performing `n(n+1)/2` comparisons for `n` steps of a run → index cached steps by step number (or `BTreeMap` / `HashMap`) for `O(1)` or `O(log n)` lookup per step.
7. **[TDD-8; item 8.5 testing ground rule]** [`crates/agent/tests/fixtures/team-cli.sh`](https://github.com/mateusz-szczyrzyca/team-agents/blob/72344f3b37ecc5d63a92a9289c323c0891158948/crates/agent/tests/fixtures/team-cli.sh#L116-L125) (also `#L178-L182`) and [`crates/agent/src/daemon/owner/rounds/tests/history_stories.rs`](https://github.com/mateusz-szczyrzyca/team-agents/blob/72344f3b37ecc5d63a92a9289c323c0891158948/crates/agent/src/daemon/owner/rounds/tests/history_stories.rs#L107) — The new `late:` action sleeps `3` seconds to order review submissions and `history_stories.rs` polls with real sleeps, contradicting TDD-8 and the item `8.5` ground rule ("Time comes from the injected clock, never from sleeping (TDD-8)") → replace sleep-based ordering with deterministic fixture synchronization or obtain an explicit human waiver before editing frozen tests.
