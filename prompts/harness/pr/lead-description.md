deviations, out of scope, skipped tests and lint suppressions with their paths and reasons. The harness publishes it
when the pull request opens and refreshes it after file-only changes too. Do not edit the pull request on GitHub.

or empty, publication continues and says that you supplied no description. If writing fails, report the error.
