Commit {{edit}} takes lines out of `{{path}}`, a test that the `RED:` commit {{red}} committed. A test is frozen from its RED commit on: later commits add tests and never edit one. If the test itself is wrong, correct it in a commit of its own that touches test files only, whose subject starts with `TEST-FIX:` and whose message says what was wrong, and name that commit in the description of the pull request under `## Tests changed after RED`. Otherwise restore the test and change the code.
